# TubePilot Studio

Flutter Android app starter.

## Build
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Run `flutter run` to test.
4. Run `flutter build apk --release` to create an APK.

This starter currently contains the app shell and navigation. YouTube account data,
analytics, video processing, and AI features are not connected yet. They will be
implemented in later phases with the required permissions and services.
